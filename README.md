## 📖 О проекте

Проект представляет собой **блог-кастомайзер** — интерактивное приложение, которое позволяет пользователю изменять внешний вид статьи в реальном времени через специальную панель настроек.

### ✨ Основные возможности

- 📱 **Сайдбар с настройками** — открывается по клику на стрелку
- 🎨 **Настройка стилей** — шрифт, размер, цвета, ширина контента
- 🔄 **Применение настроек** — изменения применяются только после нажатия кнопки "Применить"
- ↩️ **Сброс настроек** — возврат к дефолтным значениям
- 🎯 **Интуитивный интерфейс** — все настройки собраны в удобной панели

## 🎨 Интерфейс

### Панель настроек включает:

- **Шрифт** — выбор из 5 вариантов
- **Размер шрифта** — 18px, 25px, 38px
- **Цвет шрифта** — 9 цветов на выбор
- **Цвет фона** — 9 цветов на выбор
- **Ширина контента** — Широкий / Узкий
